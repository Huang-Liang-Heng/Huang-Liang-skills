# Project Type：Econometrics

在 `research.md` 基础上额外关注规格、识别与结果 provenance；Project Fold 不替代计量审计。

- Model：研究问题、核心变量/机制、识别策略高层逻辑、研究边界、必须由研究者控制的识别取舍。
- State：当前主样本、treatment/event 定义、canonical specification、当前可支持的结论、最大识别风险。
- Architecture：raw → cleaning → variables → analysis panel → specification → tables/figures。
- Invariant：正式结果必须可追溯到脚本和输入；探索规格不能自动晋升为主规格。
