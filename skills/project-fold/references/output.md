# Output：低认知负担的项目汇报

完成非平凡任务后，不默认用文件/代码修改列表作为主叙事。

## 默认顺序

1. **Current truth**：现在项目处于什么状态。
2. **Semantic delta**：本次真正使什么能力/结论发生变化。
3. **Meaning**：这对项目目标意味着什么。
4. **Human decision**：仍需用户决定什么。
5. **Details on demand**：实现、文件、测试、日志作为证据层展开。

## 信息组织

- 一段/一组编号只围绕一个认知对象。
- 同一级维度一致：全部是流程、能力、风险或决策，不混杂。
- 有顺序时用编号/因果链；无序 bullet 只用于真正平级且短的枚举。
- 优先“对象/触发 → 动作/机制 → 结果/用途”。
- 目标是决策充分压缩，不是最短摘要。

## Progressive Disclosure

默认先给 Level 0–1 的语义模型；用户需要时再展开到：

- Level 2：规则、机制、约束、例外；
- Level 3：文件、代码、数据、测试、日志。

任何层级都不能把 UNKNOWN 写成确定事实。
